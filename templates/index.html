About This Project

Project: Real-Time Chiller Monitoring and Performance Analysis

Institution: Walchand Institute of Technology

Technology stack: ESP32, Python Flask, SQLite, HTML, CSS, JavaScript, Server-Sent Events, Chart.js

Purpose: Real-time monitoring and performance analysis of a refrigeration/chiller system, including live sensor visualization, real coefficient-of-performance (COP) calculation, industrial-style alarm handling, and historical Excel reporting — built for a mechanical engineering capstone project.
